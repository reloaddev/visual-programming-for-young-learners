\subsection{Surveys}
\subsubsection{Pre-Survey}

The following pre-survey was administered to participants prior to the study. Responses were collected using a 5-point Likert scale, where (1) Disagree, (2) Partially Disagree, (3) Neutral, (4) Partially Agree, and (5) Agree.

\begin{enumerate}
	\item I have a lot of experience writing computer programs.
	\item I feel confident in solving complex programming problems.
	\item I have a lot of experience creating games or interactive programs.
	\item I have a lot of experience using text-based programming languages (e.g., Python, Java).
	\item I have a lot of experience using visual programming languages (e.g., Scratch, Orchestrator).
	\item I can confidently explain how a game can be broken down into smaller parts.
	\item I can confidently explain how a game can use state machines.
	\item I can confidently explain how events are implemented in games (e.g., click, collision).
	\item I can confidently explain how a game stores and updates data (e.g., variables or score).
	\item I know what objects are, and can implement them in games without assistance.
\end{enumerate}

\subsubsection{Post-Survey}

The following post-survey was administered to participants after the study. Responses were collected using a 5-point Likert scale, where (1) Disagree, (2) Partially Disagree, (3) Neutral, (4) Partially Agree, and (5) Agree.

\begin{enumerate}
	\item I feel confident in building a larger program (e.g., a game) using the visual programming language.
	\item I feel confident in solving complex programming problems using the visual programming language.
	\item The visual programming language made it easy to get an overview of my program.
	\item The visual programming language made it easy to organise my program into separate parts / modules.
	\item The visual programming language made it easy to connect different parts of my program using events.
	\item The visual programming language made it easy to see how data (e.g., score) is stored and updated in my game.
	\item The visual programming language made it easy to instantiate objects.
	\item I can confidently explain how a game can be broken down into smaller parts.
	\item I can confidently explain how a game can use state machines.
	\item I can confidently explain how programs respond to events (e.g., button clicks, collision).
	\item I can confidently explain how programs store and update data (e.g., variables or score).
	\item I can confidently explain how programs instantiate objects.
\end{enumerate}
