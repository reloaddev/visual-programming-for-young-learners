Introducing programming into education have become increasingly important as technologies continue to evolve. Understanding technology in general is becoming more of an essential skill, rather than a specialized field. Introducing programming and computational thinking early into education is a way schools can prepare their srudents for the future. Visual programming tools have gained popularity, as a way to make programming easier for young learners. Replacing the traditional text based syntax with a graphical representation, the tools aims to make the task of programming easier to understand. 

\subsection{Visual Programming in Education}
Visual programming tools have become popular in education along with the introducing computational thinking into curriculums. It has been shown that early exposure to computational competencies will benefit students in their future learning with software engineering\cite{grover_computational_2013}. Educational visual programming tools are often used to introduce the fundamentals and have reduced complexity. A programming language with a text-based syntax will offer more flexibility and control, it does however require learners to understand a stricter and differnt kind of abstractions then what a visual programming language will offer.

\subsubsection{Why Schools Adopt Visual Programming Tools}
Schools are adopting visual programming tools to for more engaging and simpler introduction to programming, this also support the development of computational thinking skills. Computational thinking is broadly descriped as “defining patterns, generalizing from specific instances”\cite{grover_computational_2013}. Computational thinking inlcudes a range of abilities such as pattern regognition, abstraction and algorithmic thinking, to deal with complexity. 

Tools like Scratch have been made to be an engaging and easy introduction to programming, with the ability to make games, animations or interactive stories. This allows the users to be creative and foster computational thinking skills. This can help the user learn design stratigies and problem solving skills, which can be aplied to both software engineering and nonprogramming domains\cite{resnick_scratch_2009}.


\subsection{What is Visual Programming}
Visual programming is when the programming language's paradigm lets the user create programs using graphical elements. The paradigm of a visual programming language is how the graphical elements is presented and how users use interact with them. Paradigms will have users arrange visual elements like blocks, nodes, diagrams or flowcharts into programs. Doing it this way can make programming more approachables to learners that might find text-based program harder to understand\cite{myers_taxonomies_1990}. Visual programming can be found in educational settings, game development and programns that have it included. 
The main idea for visual programming is to reduce complexity related to syntax. And having more focus on the logic and structure of the program, by using the visual elements of a chosen paradigm, to see and understand the relationships and execution flow of the program. 
The choice of paradigm often depends on what the user wants, as well as the type of programs they want to use when creating, and what they want to create. Graphical programming changes the user representation of the problem, and makes the data be prossed closer to how they would solve in the real world\cite{myers_taxonomies_1990}.


\subsection{Research Questions}
This project aims to investiage differnt visual programming paradigms, and their ability to teach the next steps in young learners jorney. Our approach to doing this investigation is to hold a workshop where young learners will be making the same game using differnt visual programming paradigms. The visual programming paradigms that will be used is Scratch with its block based paradigm and Godot Orchestrator with its node based paradigm. 
More specifically this study will investiage whether the paradigms used by Scratch or Godot Orchestrator, are more effective at teaching software design and architechture patterns. Each paradigm will have its own set of game development documents, that will focus to incorperate the same concepts. The concepts we want to teach are modularization, instantiation, event handling and statemachines. These were identified as the next steps to learn in programming education, since they are introduced early in university computer-science coureses.
This study and workshio is built on that those concepts are the next and fitting steps for a young learners. Young learners that have learned the basics and are ready to gain more experience with more advanced software topics.
This motivation is central to the study. The following research quesitons have guided both the analysis and workshop.
\begin{itemize}
    \item RQ1: How different visual programming paradigms contribute to young learners understanding of software design and architechture pattens?
    \item RQ2: What concepts does each paradigm emphasize in teaching program design?
\end{itemize}
