Introducing programming into education has become increasingly important as technologies continue to evolve.
Understanding technology in general is becoming more of an essential skill, rather than a specialized field.
Introducing programming and computational thinking early into education is a way schools can prepare their students for the future.
Visual programming tools have gained popularity, as a way to make programming easier for young learners.
By replacing traditional text-based syntax with a graphical representation, these tools aim to make programming easier to understand.

Visual programming is a paradigm where the user create programs using graphical elements.
The paradigm of a visual programming language describes how graphical elements are presented and how users interact with them.
Paradigms will have users arrange visual elements like blocks, nodes, diagrams or flowcharts into programs.
Doing it this way can make programming more approachable to learners that might find text-based program harder to understand\cite{myers_taxonomies_1990}.
Visual programming can be found in educational settings, game development and programs that have it included.

\subsection{Visual Programming in Education}
Visual programming tools have become popular in education as a means to introduce computational thinking into curriculums.
It has been shown that early exposure to computational competencies will benefit students in their future learning with software engineering\cite{grover_computational_2013}.
Educational visual programming tools are often used to introduce the fundamentals and have reduced complexity~\cite{resnick_scratch_2009}.
A programming language with a text-based syntax will offer more flexibility and control, it does however require learners to understand a stricter syntax and different kinds of abstractions than what a visual programming language will offer.

Schools are adopting visual programming tools for a more engaging and simpler introduction to programming, this also supports the development of computational thinking skills.
Computational thinking is broadly described as “defining patterns, generalizing from specific instances”\cite{grover_computational_2013}.
Computational thinking includes a range of abilities such as pattern recognition, abstraction and algorithmic thinking, to deal with complexity.

Tools like Scratch have been made in order to provide an introduction to programming, with the ability to make games, animations or interactive stories.
This allows the users to be creative and foster computational thinking skills.
This can help the user learn design strategies and problem-solving skills, which can be applied to both software engineering and nonprogramming domains\cite{resnick_scratch_2009}.

Visual programming can be used to teach the fundamentals.
The next steps in programming education would be software design.
As learners progress to topics beyond the basics, visual programming tools may provide an appropriate transition to those advanced topics.
Concepts such as modularization, event handling, instantiation and state management can be represented visually which makes them accessible for young learners.
Teaching these concepts with a visual tool may help students understand them~\cite{Chao_exploring_problemsolving_through_visual_programming_2016}.

\subsection{Research Question}
This project aims to investigate different visual programming paradigms and their ability to teach the next steps in young learners' journey.
Our approach to doing this investigation is to hold a workshop where young learners will be making the same game using different visual programming paradigms.
The visual programming paradigms that will be used is Scratch with its block-based paradigm and Godot Orchestrator with its node-based paradigm.
More specifically this study will investigate whether the paradigms used by Scratch or Godot Orchestrator are more effective at teaching software design and architecture patterns.
Each paradigm will have its own set of game development documents, that will focus to incorporate the same concepts.
The concepts we want to teach are modularization, instantiation, event handling and state management.
These were identified as the next steps to learn in programming education, since they are introduced early in university computer-science courses.
This study and workshop is built on that those concepts are the next and fitting steps for a young learners.
Young learners that have learned the basics and are ready to gain more experience with more advanced software topics.
This motivation is central to the study.
The following research question has guided both the analysis and workshop.
\begin{itemize}
    \item RQ: How do different visual programming paradigms contribute to young learners understanding of software design concepts?
\end{itemize}
